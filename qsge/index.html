QSGE · Quantitative Spatial General Equilibrium

量化空间一般均衡总览：模型类型分支清单与学习路线

贸易与空间经济学的量化工具箱。本页以"模型类型"为主轴：6 个模型分支（Armington → Eaton-Kortum → 结构引力 → Melitz → RRH → 贸易+迁移+土地）各成一页、覆盖完整流程；福利分解 ACR 与帽子代数反事实作为跨分支方法参考放在最后。

前置条件与学习依赖 · PREREQUISITES
数学/统计基础
基础微积分与偏导数、矩阵代数（向量/矩阵乘法、归一化）、概率与统计入门（CDF/PDF、期望）。能读懂 CES 效用函数的一阶条件即可，无需高级测度论。
经济学理论前置
中级微观经济学（消费者最优化、一般均衡直觉）、国际贸易理论入门（比较优势、贸易成本概念）。学过 Krugman 新贸易理论或城市经济学者优先。
软件/计算前置
Python 基础（numpy 矩阵运算）或 MATLAB 基础。引力实证部分需 Stata；空间 GE 部分需能跑 scipy.optimize。

★ 估计与反事实方法 Methods

为什么先学这三件

QSGE 的 6 个模型分支看起来不同（Armington / EK / Melitz / RRH / 贸易+迁移+土地），但它们在"做福利分析"和"做反事实"时用的是同一套工具。下面三件基础知识就是这套工具的"普通话"。先把这三件学完，再进入任何一个模型分支，你会发现每个分支的"福利"和"反事实"章节只是把同一个公式换了个参数代入。

① 帽代数反事实求解
难度：进阶

是什么：Dekle-Eaton-Kortum (2007) 的 exact hat algebra。用 $\hat x = x'/x$ 把均衡方程重写为"变化率"形式，只用观测到的基准贸易份额 $\lambda_{ni}$ 和外生冲击 $\hat\tau_{ni}$，就能迭代出反事实均衡，不需要知道 $T_i, w_i$ 的水平值。

在哪些分支中使用：Armington（CES 份额）、EK（Fréchet 份额）、Melitz-Pareto（Pareto 门槛份额）、RRH（嵌套：通勤+贸易）、贸易+迁移+土地（三市场帽子）——所有反事实求解都用精确帽子代数。

进入基础知识库 · 帽代数 →

② 福利分解 (ACR)
难度：进阶

是什么：Arkolakis-Costinot-Rodriguez-Clare (2012) 的充分统计量公式 $\hat W_n = \hat\lambda_{nn}^{-1/\varepsilon}$。无论模型是 Armington、EK 还是 Melitz-Pareto，只要满足 CES + 单一要素 + 贸易平衡，福利变化只取决于国内份额变化和贸易弹性 $\varepsilon$ 两个统计量。

在哪些分支中使用：Armington（$\varepsilon=\sigma-1$）、EK（$\varepsilon=\theta$）、Melitz（$\varepsilon=\theta$，Pareto 形状）、RRH（土地/通勤扩展）、贸易+迁移+土地（福利分解扩展）——所有 QSGE 分支的福利分析都用 ACR 框架。

进入基础知识库 · 福利分解 →

③ 结构引力估计 (PPML)
难度：进阶

是什么：Anderson-van Wincoop (2003) 把引力方程从回归工具升级为结构模型；PPML + 双向固定效应处理零贸易流与多边阻力。估出的贸易弹性 $\theta$ 是 ACR 福利公式和帽代数反事实的"输入参数"。

在哪些分支中使用：所有需要校准贸易弹性的分支（Armington / EK / Melitz / RRH / 贸易+迁移+土地）；结构引力页本身就是估计方法分支。

进入结构引力与 PPML →

学习建议

推荐顺序：③ 引力估出 $\theta$ → ② ACR 公式把 $\theta$ 变成福利 → ① 帽代数把 $\theta$ 变成反事实 $\hat\lambda_{nn}$。三件工具合起来就是 QSGE 论文的"实证 → 福利 → 反事实"标准三段。学完这三件再去看任何模型分支，都能在它的"福利 / 反事实"章节看到这三件工具的影子。

03 QSGE 论文的典型写作范式

QSGE 论文的结构介于纯理论与纯实证之间：先写模型，再校准/估计参数，最后做反事实。

章节内容对应分支
1. Introduction政策问题 + 模型一句话 + 主要量化发现全局
2. Model偏好、技术、贸易成本、均衡条件（必须完整写出）对应模型分支（1-6）
3. Calibration / Estimation参数来源、贸易弹性估计、矩匹配、数据描述分支 3（引力估计）+ 各分支校准
4. Welfare DecompositionACR 公式、福利变化分解到各 margin方法参考 · ACR（并入各分支）
5. Counterfactual帽子代数求解：改变贸易成本/迁移成本，重算均衡方法参考 · 帽子代数（并入各分支）
6. Robustness换贸易弹性、换模型设定、换数据对应模型分支
7. Conclusion政策含义 + 模型局限全局
QSGE 论文最常见的写作事故

① 模型章节跳步，直接从效用跳到数值结果；② 贸易弹性（trade elasticity）不引用估计来源；③ 反事实求解不报告帽子代数的迭代收敛；④ 福利分解只报总量不报 margin；⑤ 不做 model fit 就宣称"模型解释了 X%"。

04 软件与工具清单

MATLAB

QSGE 主力。帽子代数的矩阵运算、多区域 GE 求解、Dekle-Eaton-Kortum 迭代。经典代码（DKK 2007）均为 MATLAB。

Python

numpy/pandas 做贸易数据整理；scipy.optimize 做均衡求解；空间经济学 Python 工具链越来越成熟。

Stata（实证部分）

引力方程的 PPML 估计用 Stata 的 ppmlhdfe 命令；贸易数据清洗用 Stata。

数值方法

定点迭代（fixed point iteration）、帽子代数 hat algebra、Dekle-Eaton-Kortum 反事实算法。

数据来源

Comtrade / CEPII BACI（双边贸易）、GTAP（投入产出）、世界银行 WDI、中国海关数据库、城市统计年鉴。

经典代码库

RIH 主页（Redding）；Macroeconomics 空间工具包；GitHub 搜 "quantitative spatial"；ACR (2012) replication。

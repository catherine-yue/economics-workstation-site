02 四阶段学习路线

从零基础到独立撰写顶刊论文的全局节奏建议——四大领域可并行，但每个领域内部应按其索引页路线循序推进。

从零基础到独立发表

Phase 1 · 第1-2月
基础筑基
掌握 Stata 基础与数据清洗流程；装好 MATLAB + Dynare；复习微观/宏观经济学基础，理解最优化与一般均衡直觉。对应各领域入门页。
Phase 2 · 第3-4月
方法入门
实证：OLS / 固定效应 / IV / DID；DSGE：RBC 与 NK 三方程建模与 Dynare 求解；结构：MLE / 线性 GMM 与离散选择入门；QSGE：Armington 模型。
Phase 3 · 第5-7月
进阶深化
实证：RDD / 交叠 DID / 稳健性体系；DSGE：中尺度 SW / 金融摩擦 / 贝叶斯估计；结构：BLP / 动态结构 / 生产函数；QSGE：EK / Melitz / 福利分解。
Phase 4 · 第8月+
前沿写作
复现经典论文，选 1-2 个方向深入（如 HANK、SMM、RRH 空间 GE），完成自己的论文初稿，对标《经济研究》《管理世界》等中文顶刊规范。

04 站点使用指南

这是一个"教程站"而非"链接站"。每一页都有完整的公式推导、可运行代码与论文范例。

从零开始怎么学

  1. 先确定你的方向：实证、DSGE、结构估计、QSGE 选一个主攻，其余了解即可。
  2. 进入对应领域索引页，按"分支 taxonomy"找到你要学的分支。
  3. 从该分支最"入门"的页面开始，按页面内目录（TOC）逐节阅读。
  4. 每段代码都复制到本地跑一遍，改参数、改数据，观察结果变化。
  5. 学完一个分支，回到索引页看"论文写作范式"，尝试复现一篇经典论文。

每页内部结构说明

  • 面包屑 + 页面标题：告诉你当前位置与本页一句话定位。
  • 本页目录（TOC）：页内锚点导航，长文快速跳转。
  • 正文分节：概念直觉 → 公式推导 → 完整代码 → 论文范例 → 常见错误。
  • 提示框：tip / warning / danger 三级，标出新手最易踩的坑。
  • 底部翻页：上一页 / 下一页，按学习顺序线性推进。
  • 侧边栏：全站 95 页导航，当前页高亮，随时跳转。

四大领域的关系

实证是一切经验研究的基础，先学它能建立"用数据说话"的直觉。DSGE 与结构估计共享"微观基础 + 最优化 + 反事实"的骨架，学会一个另一个会很快。QSGE 是 DSGE/结构估计在贸易与空间领域的特化应用，建议在掌握 NK 或离散选择后再进入。

软件环境准备

  • 实证：Stata 17+（必装 reghdfe、estout、winsor2 等外部命令）。
  • DSGE：MATLAB R2018b+ 与 Dynare 5.x（Optimization + Statistics 工具箱）。
  • 结构估计：MATLAB（fmincon/knitro）或 Python（numpy/scipy）。
  • QSGE：MATLAB 或 Python（帽子代数向量运算）。

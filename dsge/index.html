DSGE · Dynamic Stochastic General Equilibrium

DSGE 模型总览：分支 Taxonomy 与学习路线

现代宏观经济学核心方法论的完整地图——从 RBC 基准到新凯恩斯三方程，从中尺度模型到金融摩擦与异质性主体。本页告诉你 DSGE 领域有哪些分支、每个分支下有哪些模型、对应哪页教程。

前置条件与学习依赖 / PREREQUISITES
数学 / 统计基础本科级微积分、概率统计即可；本页只做路线导航，不涉及推导，不要求先学任何数值方法。
经济学理论前置中级宏观经济学（Solow-Swan、IS-LM、AD-AS）与 GDP、通胀、利率等基本概念。
软件 / 计算前置无；本页是总览与学习路线，不写代码。后续建模页再按要求装 MATLAB+Dynare。
站内前置页面无模型页依赖，是整个 DSGE 分支的入口；建议先看工作站首页总览。

00 求解与估计方法 Methods

DSGE 模块分为模型分支与求解与估计方法两大类。下面这组跨分支通用方法单独成页——先掌握这些工具，再进入模型分支学习：每个分支都在反复使用同一套模型构建、一阶条件、稳态、线性化、扰动求解、Dynare、贝叶斯估计与 IRF 模拟流程，不必在每个分支里从零学一遍。每项标注：是什么 · 难度 · 对应方法页 · 在哪些分支中使用。

① 稳态求解进阶

是什么：无冲击时所有内生变量保持不变的那个"锚"；解析推导 + fsolve 数值解 + Dynare steady_state_model。

在哪些分支使用：所有分支的展开点——RBC / NK三方程 / 中尺度SW / 小国开放 / 金融摩擦 / 财政货币规则 / TANK-HANK / 适应性学习。

📚 基础知识页 · 03-steady-state →
② 对数线性化进阶

是什么：在稳态处做一阶泰勒展开，把非线性 FOC 翻译成线性理性预期系统 $\hat x_t=\ln x_t-\ln\bar x$。

在哪些分支使用：几乎所有线性求解的 DSGE 分支——RBC / NK三方程 / SW / 小国开放 / 金融摩擦 / 财政货币规则 / TANK-HANK / 适应性学习。

📚 基础知识页 · 04-log-linearization →
③ 扰动法（一阶/二阶/三阶）进阶→前沿

是什么：在稳态对决策规则做泰勒展开；一阶 ≡ 对数线性化，二阶/三阶才捕捉风险溢价与不确定性效应（含 pruning）。

在哪些分支使用：RBC / NK三方程 / SW（二阶+pruning）/ 小国开放 / 金融摩擦 / 财政货币规则 / 适应性学习；HANK 不能只用一阶扰动。

📚 基础知识页 · 15-perturbation-methods →
④ Dynare 求解实操入门→进阶

是什么：.mod 文件结构（var / model / parameters / steady / shocks）与 steady; check; stoch_simul 全流程。

在哪些分支使用：凡用 Dynare 的分支都从这里起步——RBC / NK三方程 / SW / 小国开放 / 金融摩擦 / 财政货币规则 / TANK。

📚 基础知识页 · 05-dynare-solving →
⑤ 贝叶斯估计进阶

是什么：用 MCMC（Metropolis-Hastings）把模型参数校准到数据，先验 + 似然 + 后验、观测方程与收敛诊断。

在哪些分支使用：中尺度 SW（主力），并推广到 NK三方程 / RBC / 小国开放 / 金融摩擦 / 财政货币规则。

📚 基础知识页 · 06-bayesian-estimation →
⑥ 脉冲响应 IRF 与模拟入门→进阶

是什么：读 IRF、方差分解、历史分解——求解结果的"看图说话"，论文标配图。

在哪些分支使用：所有模型分支的收尾解读——RBC / NK三方程 / SW / 小国开放 / 金融摩擦 / 财政货币规则 / TANK-HANK / 适应性学习。

📚 基础知识页 · 08-irf-simulation →
🧭 建议学习顺序

① 模型构建 → ② 一阶条件推导 → ③ 稳态求解 → ④ 对数线性化 → ⑤ Dynare 求解 → ⑥ IRF 模拟 →（进阶）扰动法高阶 → 贝叶斯估计。把这条工具链走通一遍，再从下面 §01 任选一个模型分支深入。

03 DSGE 论文的典型写作范式

无论英文 AER 还是中文《经济研究》，DSGE 论文的章节结构高度趋同。

章节内容对应分支
1. IntroductionStylized facts + 文献缺口 + 本文贡献（3 条 bullet）全局
2. The Model家庭/厂商/政府/市场出清，每个 agent 写优化问题 + 一阶条件分支 2
3. Calibration / Estimation参数校准依据 + 先验设定 + 估计结果（后验均值、置信区间）分支 3
4. Results: IRF & Variance Decomp脉冲响应图 + 方差分解表，解释经济含义分支 5
5. Welfare / Counterfactual反事实政策模拟（如换 Taylor rule 系数，福利损失变多少）分支 4 + 5
6. Robustness换参数、换模型设定、换样本期分支 3
7. Conclusion3 段：总结 + 政策含义 + 局限全局
最常见的写作事故

① 引言不报告 stylized facts 直接上模型；② 模型章节只贴方程不解释 friction 的经济直觉；③ 校准参数不引用来源；④ IRF 图只画不解读；⑤ 不做 welfare analysis 就建议政策。

04 软件与工具清单

MATLAB R2018b+

DSGE 主力环境。需要 Optimization Toolbox（fsolve）与 Statistics Toolbox（Bayesian）。学生可通过学校许可证免费安装。

Dynare 5.x

DSGE 事实标准工具。把 .mod 文件翻译成 MATLAB 代码后求解。官网 dynare.org 下载，工作目录必须纯英文无空格。

Python 备选

序列建模可用 quantecon / sequence_jacobian 库（HANK 方向）。标准 NK 模型仍推荐 Dynare。

数值求解

fsolve（稳态）、定点迭代（value function iteration）、krylov 方法（大型线性系统）。

贝叶斯工具

Dynare 内置 MH 抽样；Geweke 收敛诊断；Brooks-Gelman-Rubin 统计量；trace plot。

文献与代码

Galí (2015) 教材配套代码；SW (2007) replication；CEE (2005) 原始代码。GitHub 搜 dynare example。
